## About Me

<img align="right" width="360" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" />

**Most AI projects never leave the demo stage. I build the ones that do.**

I'm a Computer Science student from Lahore who builds AI systems end to end: model logic, backend, interface, and the part everyone skips, which is making it reliable enough for real people to use every day.

- Built an **AI CV screening system now used in production** by the HR team at Honda Atlas Cars Pakistan
- Built an **agentic lead-scoring pipeline** for Honda's sales team, with a human approving every message
- Focus: **LLM apps, AI agents, RAG, backend systems**
- Also into **cybersecurity and digital forensics**
- Currently learning **multi-agent orchestration with LangGraph**
